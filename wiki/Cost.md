# 成本

> 所有价格是**量级参考**，不是报价。以阿里云控制台的实时价格为准。

## 拆开算

| 项 | 计费方式 | 量级 |
|---|---|---|
| 香港竞价实例 2C2G | 按小时 | 约 **¥0.02–0.05 / 小时**（实测出价 0.03） |
| 系统盘 40G ESSD | 按小时 | 约 ¥0.01 / 小时 |
| 公网流量 | **按量** | 约 **¥0.5–0.8 / GB** |

**流量是大头。** 如果只是刷网页、看文档，一个月几 GB 就够；
看视频才会吃流量。

## 三种典型用法

| 用法 | 每月估算 |
|---|---|
| 每天 2 小时、10 GB | **约 ¥5–15** |
| 每天 4 小时、40 GB | **约 ¥20–40** |
| 常开、100 GB | **约 ¥60–90** |

## 省钱的关键动作

```bash
./yi down          # 用完就销毁，这是唯一真正省钱的操作
```

**`disconnect` 不省钱**——它只是断开代理，机器还在跑、还在计费。

## 护栏

配置文件里可以设上限：

```toml
[budget]
max_hours = 720     # 累计运行小时
max_gb = 300        # 累计流量
```

超过时 `./yi status` 会告警。它**不会**替你自动关机——自动关机听起来聪明，
真出事的时候你只会觉得"网莫名断了"。护栏负责提醒，决定权留给你。

## 和"买 VPS 跑安装脚本"比

| | 本项目 | 包月 VPS |
|---|---|---|
| 计价 | 按小时 + 按流量 | 固定月付 |
| 不用时 | **¥0** | 照样付 |
| 一个月几十小时 | ¥5–15 | 不便宜 |
| 24 小时常开跑流量 | 不如包月划算 | 更划算 |

所以：**断续使用，竞价最便宜；长期常开跑大流量，包月更省。**
