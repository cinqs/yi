# 驿 · Yi

用**一年几十块**跑起一台自己的代理：一条命令买下阿里云香港**竞价实例**，
自动装好 `VLESS + XTLS-Vision + REALITY` 服务端，并在本机连上。

```bash
./yi up          # 买机器 → 装服务端 → 回环自检 → 生成客户端配置
./yi connect     # 起代理内核 + 开系统代理
./yi down        # 销毁，停止计费
```

名字取自古代**邮驿**制度——文书传递靠沿途驿站换马续行，**马换、路不换**。
这里换的是随时可能被回收的抢占式实例：**机器换了，你的客户端配置不换**。

## 它为什么和"买个 VPS 跑安装脚本"不一样

那套教程放到**抢占式实例**上会立刻崩：机器随时被回收，IP 变了、密钥变了、
客户端配置全废。这个项目认真处理了这些事：

- **期望状态 + 调和循环**：内核崩了、服务端换地址了、系统代理被人关了，8 秒内自己纠正
- **凭据持久化**：UUID 和 REALITY 密钥对存在本地，重建出来对客户端仍是"同一台"
- **绝不把系统代理指向没人监听的端口**：这类失误的代价是整机断网，所以宁可连不上
- **不自己造协议**：内核用成熟开源实现（本机 `mihomo`，服务端 `Xray-core`）

技术细节见 [架构](Architecture)。
