# 常见问题

## 要域名吗？要证书吗？

**都不要。** 这是选 REALITY 的主要理由：它借用真实站点的证书，天生不需要你
拥有域名，也就不存在 ACME 续期失败、证书过期这类"半夜网站打不开"的故障源。

（也正因为如此，这个项目**不做** CDN + TLS + WebSocket 那套方案——那套必须有域名。）

## 真的能便宜到那个程度吗？

个人用法大约 **¥20–50/月**。拆开看：

| 项 | 量级 |
|---|---|
| 香港竞价实例 2C2G | 约 ¥0.02–0.05 / 小时（实测出价 0.03） |
| 公网流量（按量计费） | 约 ¥0.5–0.8 / GB |

关掉机器就不计费。详见 [成本](Cost)。

## 机器被回收了，我的网会断多久？

后台守护发现实例消失后自动重买，实测**约 2 分钟**恢复，中间**不需要你动手**。
而且因为凭据（UUID + REALITY 密钥对）持久化在本地，重建出来的服务器对客户端来说
仍然是"同一台"，Mac 端连配置都不需要重导。

## 会不会把我自己的网搞断？

这是被认真对待过的风险。任何时候内核没在监听，系统代理**都不会**被指向那个端口
——内核起不来就自动回退直连。历史上这里出过一次严重 bug（系统代理指向死端口导致
整机断网），现在有多层保险和回归测试守着。

## 和 Clash Verge Rev / v2rayNG 冲突吗？

不冲突，它们用的是不同的本地端口。`yi` 会自动避让 7897（Clash Verge 的常用口）。

## 能同时连几台设备？

单台服务器没有硬上限，`yi` 的手机订阅可以给多台设备用。

## 支持 Windows / Linux 吗？

**服务端不挑平台**，协议是标准的。客户端目前只提供了 macOS App；
Windows/Linux 你可以直接用生成的 `mihomo.yaml` 或 `singbox.json`。
（生成的文件在 `~/.config/yi/profiles/`。）

## 我能自己改协议吗？

不建议。项目刻意**不自己实现协议**，内核用成熟开源实现。
想换协议的话，`src/yi/bootstrap.py` 里的服务端配置模板和
`src/yi/configgen.py` 里的客户端生成要**一起改**，并且必须同时验证
Android 和 macOS 两端——有一条单元测试专门锁这个契约
（`tests/test_client_contract.py`）。

## 为什么不支持按月包年包月的 ECS？

支持的，把 `spot_strategy` 相关配置拿掉就行。但包月贵十倍以上，
和这个项目"极便宜"的出发点冲突，所以默认走竞价。

## 会不会违反阿里云的条款？

竞价实例是阿里云的正规产品，按量付费、正常使用没有条款问题。
但**请自行确认你所在的司法辖区对跨境代理服务的适用规定**——
这个项目的定位是"在你自己租用的服务器上搭个工具"，仅此而已。
